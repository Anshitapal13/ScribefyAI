# 🎓 Scribefy: AI-Powered Study Companion

**"Your Smart Study BFF"**

Scribefy is a comprehensive web-based platform designed to transform passive video consumption into an active, engaging, and highly accessible learning experience. By leveraging artificial intelligence, Scribefy generates structured notes, answers contextual questions, and creates interactive quizzes directly from YouTube videos.

---

## ✨ Key Features

* 📝 **Intelligent YouTube Summarizer:** Paste a YouTube URL to instantly generate a concise, "bite-sized" text summary. Each summary point includes clickable timestamps that navigate directly to the relevant video segment.
* 🤖 **AI Doubt Solver:** A 24/7 conversational AI ("brainy bot") that uses the video's transcript as a source of truth to answer your specific questions contextually.
* 🧠 **Interactive Quiz Generator:** Automatically create custom, dynamic quizzes (MCQs, True/False) based on the video content to promote active recall and test knowledge retention.
* 🤝 **Collaborative Study Rooms:** Virtual "chill zones" for focused learning, featuring real-time group chat and perfectly synchronized shared Pomodoro timers.
* 🌟 **Accessibility & Neurodivergent-Friendly:** Built with a low-cognition, distraction-free UI. Features include deliberate content "chunking", built-in Text-to-Speech (TTS) for audio playback, high contrast, and full WCAG 2.1 AA compliant keyboard navigability.

---

## 🛠️ Technology Stack

Scribefy is built on a highly scalable, decoupled three-tier architecture:

### Frontend (Presentation Tier)
* **Framework:** React (Single Page Application)
* **UI/UX:** Figma-designed, responsive, mobile-first approach for efficient user experience

### Backend & Infrastructure (Service Tier)
* **Platform:** Google Firebase Suite
* **Auth:** Firebase Authentication
* **Database:** Firebase Real-time Database / Firestore
* **Serverless Logic:** Firebase Cloud Functions (secure API key management)
* **Hosting:** Firebase Hosting

### AI Core & Data (Intelligence Tier)
* **Generative AI:** Google Gemini API (Multimodal analysis, structured JSON generation, conversational AI)
* **Data Pipeline:** YouTube Data API v3 (Metadata and transcript extraction)

## 🎯 Target Audience

* **The Student:** Quickly summarize long lectures and generate practice quizzes before exams.
* **The Professional:** Extract actionable insights and key takeaways from hour-long webinars in minutes during commutes.
* **The Neurodivergent Learner:** Overcome executive dysfunction with "chunked" summaries, low-distraction interfaces, and non-judgmental AI assistance.
